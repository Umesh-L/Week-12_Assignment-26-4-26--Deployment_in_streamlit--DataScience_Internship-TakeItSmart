# Streamlit deployment of all the Machine Learning (Supervised(Classification and Regression) and Unsupervised) projects 🚀

This folder contains four deployed Streamlit machine learning projects built during the Take It Smart internship. Each app is packaged with its own notebook, dataset, and deployed web interface.

## Live Streamlit Apps

- [House Price Prediction (Regression)](https://house-price-prediction--regression--umesh-l.streamlit.app/)
- [HR Attrition Prediction (Classification)](https://hr-attrition-prediction--classification--umesh-l.streamlit.app/)
- [Customer Churn Prediction (Classification)](https://customer-churn-prediction--classification--umesh-l.streamlit.app/)
- [Customer Segmentation using K-Means Clustering](https://customer-segmentation-using-k-means-clustering--umesh-l.streamlit.app/)

## Projects Overview

### 1. House Price Prediction (Regression) 🏠

Predicts house prices from structured property features such as square footage, bedrooms, bathrooms, lot size, garage size, and neighborhood quality.

- Project type: Supervised Machine Learning (Regression)
- Main notebook: [House_Price_Prediction_(Regression).ipynb](House%20Price%20Prediction%20(Regression)/House_Price_Prediction_(Regression).ipynb)
- Dataset: [house_price_regression_dataset.csv](House%20Price%20Prediction%20(Regression)/house_price_regression_dataset.csv)
- Deployment: [Live App](https://house-price-prediction--regression--umesh-l.streamlit.app/)
- Main idea: Compare regression models and choose the one with the best prediction quality

### 2. HR Attrition Prediction (Classification) 👥

Predicts whether an employee is likely to leave the company based on HR, compensation, and work-life features.

- Project type: Supervised Machine Learning (Classification)
- Main notebook: [HR_Attrition_Prediction_(Classification).ipynb](HR%20Attrition%20Prediction%20(Classification)/HR_Attrition_Prediction_(Classification).ipynb)
- Dataset: [HR-Employee-Attrition.csv](HR%20Attrition%20Prediction%20(Classification)/HR-Employee-Attrition.csv)
- Deployment: [Live App](https://hr-attrition-prediction--classification--umesh-l.streamlit.app/)
- Main idea: Identify high-risk employees early so retention actions can be planned

### 3. Customer Churn Prediction (Classification) 📞

Predicts whether a telecom customer is likely to churn using customer account and service usage details.

- Project type: Supervised Machine Learning (Classification)
- Main notebook: [Customer_Churn_Prediction_(classification).ipynb](Customer%20Churn%20Prediction%20(Classification)/Customer_Churn_Prediction_(classification).ipynb)
- Dataset: [telecom_churn_data.csv](Customer%20Churn%20Prediction%20(Classification)/telecom_churn_data.csv)
- Deployment: [Live App](https://customer-churn-prediction--classification--umesh-l.streamlit.app/)
- Main idea: Help businesses identify customers who may leave and take retention actions

### 4. Customer Segmentation using K-Means Clustering (Unsupervised ML) 🎯

Segments customers into meaningful groups using clustering so businesses can target each segment more effectively.

- Project type: Unsupervised Machine Learning
- Main notebook: [Customer_Segmentation_using_K_Means_Clustering.ipynb](Customer%20Segmentation%20using%20K-Means%20Clustering%20(Unsupervised%20ML%20model)/Customer_Segmentation_using_K_Means_Clustering.ipynb)
- Dataset: [Customer Purchasing Behaviors.csv](Customer%20Segmentation%20using%20K-Means%20Clustering%20(Unsupervised%20ML%20model)/Customer%20Purchasing%20Behaviors.csv)
- Deployment: [Live App](https://customer-segmentation-using-k-means-clustering--umesh-l.streamlit.app/)
- Main idea: Group similar customers based on purchase behavior for marketing insights
